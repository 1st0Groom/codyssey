## 1. 스택(stack) - 나중에 온 놈이 먼저 나간다 (last in first out)
- **개념** : 원통형 과자(프링글스)를 생각하면 편함. 맨 마지막에 넣은(Push) 데이터를 가장 먼저 꺼낸다(Pop).
- **Mini Redis와의 연결고리**: 사용자가 터미널에 입려갰던 명령어 히스토리를 뒤로 가기로 불러올 때 스택 구조가 쓰임, 가장 마지막에 친 명령어가 제일 먼저 나와야 함

## 2. 큐(queue) - 먼저 온 놈이 먼저 나간다 (first in first out)
- **개념** : 놀이공원 줄서기, 은행 창구. 먼저 온 사람이 먼저 서비스를 받는다.
- **Mini Redis와의 연결고리**: 보너스 과제 메세징 기능 만들 때 필수, A라는 채널에 구독자들이 모여있을 때, 발행자가 메세지를 보내면 줄 서 있는 순서대로 구독자들에게 메시지를 안전하게 배달해야 함.

## 3. 덱(Deque - Double Ended Queue) - 양쪽 다 열려있는 파이프
- **개념** : 양쪽 끝에서 모두 넣고 뺄 수 있는 만능 자료구조, 스택과 큐의 장점을 합친형태임. 파이썬의 collections 모듈에 deque가 있음.
- **Mini Redis와의 연결고리**: 이중 연결리스트(Doubly Linked List)가 사실상 덱을 밑바닥부터 직접 짜는 것임. 그래야 시간복잡도를 O(1) 속도로 데이터를 맨 앞(최근 사용)이나 맨 뒤 (LRU)로 옮길 수 있음.
