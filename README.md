# Codyssey AI 올인원 과정

코디세이 AI 올인원 과정에서 학습하고 실습한 내용들을 정리한 레포지토리입니다. 각 미션별로 디렉토리를 나누어 프로젝트와 학습 로그를 기록하고 있습니다.

## 💻 개발 및 시연 환경
- **개발 환경**: Ubuntu가 설치된 노트북 환경에서 진행
- **시연 환경**: 학습장 내 비치된 Mac 장비에 SSH로 원격 접속하여 진행

## 📂 폴더 구조 및 학습 내용

### Essential (E) 과정
- **E1-1 (AI/SW 개발 워크스테이션 구축)**
  - 터미널(CLI) 기본 조작 및 파일 권한(rwx) 관리 시스템 이해
  - Docker 설치, 컨테이너 실행, `Dockerfile`을 이용한 커스텀 이미지 제작
  - 컨테이너 포트 매핑, 볼륨(Volume), 바인드 마운트를 활용한 데이터 영속성 및 동기화 실습
  - Git 사용자 설정 및 로컬/원격 레포지토리 연동
- **E1-2 (파이썬 객체지향 프로그래밍)**
  - 파이썬 클래스 기반 설계 및 객체 지향 개념 학습
  - CLI 기반 퀴즈 게임 애플리케이션 개발 실습

### Basic (B) 과정
- **B1-1 (시스템 관제 자동화 스크립트)**
  - 리눅스 환경에서의 시스템 모니터링 및 관제를 위한 자동화 쉘 스크립트 작성
- **B1-2 (리눅스 프로세스 및 리소스 트러블슈팅)**
  - 시스템 프로세스 관리, CPU/메모리 리소스 분석 기법 학습
  - 장애 상황에 대한 트러블슈팅 및 로그 분석
- **B3-1 (Mini Redis 개발)**
  - 기본 자료구조를 활용한 인메모리 Key-Value 데이터베이스(Redis)의 핵심 기능 직접 구현
- **B3-2 (Mini Git 개발)**
  - 버전 관리 시스템(Git)의 내부 원리(DAG, 커밋 트리, 브랜치 관리 등) 이해
  - 핵심 Git 기능 및 명령어를 CLI 기반으로 직접 구현
