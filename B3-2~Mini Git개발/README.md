# Mini Git 

Mini Git은 분산 버전 관리 시스템 Git의 핵심 구조(DAG)와 명령어들을 Python으로 모사한 CLI 기반 미니 프로젝트입니다. 외부 그래프 라이브러리 및 표준 정렬 API를 사용하지 않고, 직접 탐색과 정렬 알고리즘을 구현하여 Git의 동작 원리를 체득하는 것을 목표로 합니다.

## 주요 기능

1. **저장소 초기화 및 브랜치 관리**
   - `INIT <user_name>`: 새로운 저장소를 초기화하고 `main` 브랜치를 생성합니다.
   - `BRANCH <branch_name>`: 현재 `HEAD`를 가리키는 새로운 브랜치를 생성합니다.
   - `SWITCH <branch_name>`: 활성화된 브랜치를 변경합니다(`HEAD` 이동).

2. **커밋 관리**
   - `COMMIT <message>`: 현재 브랜치의 최신 커밋을 부모로 하여 새 커밋을 생성합니다. 커밋 시 역색인(Inverted Index)을 갱신하여 빠른 검색을 지원합니다.

3. **조회 및 정렬 (LOG)**
   - `LOG`: 저장소의 모든 커밋을 위상 정렬(Topological Sort)하여, 부모 커밋이 자식 커밋보다 먼저 출력되도록 합니다.
   - `LOG --sort-by=date`: 작성 시간 기준으로 커밋을 정렬(직접 구현한 병합 정렬)하여 출력합니다.
   - `LOG --sort-by=author`: 작성자 이름 기준으로 정렬하여 출력합니다.

4. **탐색 (PATH, ANCESTORS)**
   - `PATH <commit1> <commit2>`: BFS 알고리즘을 통해 무방향 간선 기준으로 두 커밋 간의 최단 경로를 탐색합니다.
   - `ANCESTORS <commit_hash>`: 특정 커밋에서 도달 가능한 모든 조상 커밋(부모 노드 탐색)을 출력합니다.

5. **역색인 기반 검색 (SEARCH)**
   - `SEARCH <keyword>`: 커밋 메시지를 토큰화해 역색인을 만들고, 모든 커밋을 순회하는 것보다 빠른 성능으로 단어가 포함된 커밋을 검색합니다.
   - `SEARCH --author=<name>`: 특정 작성자가 작성한 커밋들을 조회합니다.

## 실행 방법

- **개발 환경**: Python 3.10 이상
- 다음 명령어를 통해 실행할 수 있습니다:

```bash
python main.py
```

## 시스템 구조 및 알고리즘

- **DAG 기반 그래프 탐색**: 커밋 데이터는 방향성 비순환 그래프(DAG) 구조로 저장되며 BFS(너비 우선 탐색)를 이용해 최단 경로 및 조상을 탐색합니다. `LOG` 시 위상 정렬을 통해 커밋 순서를 결정합니다.
- **Merge Sort 구현**: `utils.py`에 자체적으로 작성된 병합 정렬 알고리즘(`merge_sort`)을 사용하여 파이썬 표준 라이브러리 제약을 극복합니다.
- **역색인(Inverted Index)**: 빠른 검색을 위해 단어 및 작성자별 커밋 매핑 테이블을 구현했습니다.
